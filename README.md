# Bibiana — website concept

A home page concept for [Bibiana](https://www.facebook.com/bibiana2001), a Bangladeshi fashion house built on hand embroidery and traditional craft since 2001. Not the official website.

## Stack

Next.js (App Router), Tailwind CSS v4, Lenis, GSAP, NumberFlow, Lucide. Bun is the package manager.

## Run

```bash
bun install
bun run dev
```

## Check

```bash
bun run typecheck
bun run lint
bun run build
```

## Where things live

- `lib/content/` — all page copy, contacts and image imports
- `components/sections/` — one file per page section
- `app/globals.css` — colour, type and spacing tokens
